# A9 – Pulleys

## Belt Analysis

I did this analysis on paper because this method was easiest for the equations and freebody diagrams. I first drew a diagram and FBD for the pulleys. Then I labeled the knowns and started making equations to solve for unknowns. I did this for both the static and dynamic cases. From here it allowed me to find the forces on the upper and lower legs of the pulley. This then allowed me to find the required diameter of belt along with the required length of the belt.
